# Snake Game — Python

Implémentation du jeu Snake en Python dans le terminal, avec menu interactif, gestion du score, écran de game over et choix entre 3 terrains de jeu.

**Outils :** Python · Curses

---

## Contexte

Projet final de la mineure Informatique - Licence Économie  
Université Paris 1 Panthéon-Sorbonne - mars 2023  
Réalisé en solo

---

## Fonctionnalités

- **Menu principal** — navigation au lancement du jeu
- **3 terrains de jeu** — niveaux avec configurations différentes
- **Système de score** — points affichés en temps réel
- **Écran de game over** — avec score final et option de rejouer

---

## Lancer le jeu

```bash
python snake.py
```

> Nécessite Python 3. Aucune dépendance externe.
